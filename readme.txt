    2、模型训练，定义模型训练的函数

            ## 每一轮都要保存一个val的loss和acc到列表里
        #7* epoch 轮次循环，每一轮里包括train和val的批次循环
            ##1、每个轮次里也还有参数
                 包括train、val的loss，corrects，num
            ##2、训练循环：把一整个批次里的图片取出来
                    特征和标签放设备

                    保存output的概率最大的下标
                    计算每个批次的平均损失
                    初始化梯度
                    反向传播
                    更新参数
                    把每个批次的loss加到一起成为一轮的总loss
                    统计预测正确的个数
            ##3、验证循环：把验证集批次里拿出来
                    特征和标签放设备

                    保存output的概率最大的下标
                    计算每个批次的平均损失
                        不需要更新参数
                    把每个批次的loss加到一起成为一轮的总loss
                    统计预测正确的个数
            ##4、保存训练集和验证集每个轮次的平均loss和acc并打印
            ##5、每轮要保存验证集准确率最高的模型参数best_model_wts
        #8、轮次循环结束，best_model_wts保存到.pyh文件
        #9、pandas把最开始初始化的画图参数等数据转换成二维
